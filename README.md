# CPU 网速悬浮窗

一个使用 C# / WPF 编写的 Windows 桌面小组件，实时显示：

- CPU 使用率
- CPU 温度
- 当前下载速率
- 当前上传速率
- 可选择最近 1、5 或 10 分钟的上传/下载实时网速曲线
- 各监控项目独立开关
- 自动或手动选择温度传感器
- 迷你长条监控体与完整监控面板双模式

## 使用已经编译好的程序

运行 `publish\CpuNetWidget.exe`。程序默认置顶；点击右上角齿轮可以直接打开设置，右键托盘图标可以：

- 显示悬浮窗
- 隐藏悬浮窗
- 打开独立设置界面
- 退出程序

主窗口可以从任意非按钮区域拖动。点击标题栏的最小化按钮会隐藏到系统托盘，双击托盘图标可以恢复；点击红色 `×` 会完全退出程序。

超窄迷你长条顶部显示 CPU 环形进度，下面依次纵向显示温度、下载和上传速率。双击长条可展开完整面板，完整面板中的 `◉` 按钮可缩回迷你模式；右键监控条可打开托盘菜单。把监控条拖近当前显示器的左、右、上或下边缘后，它会自动吸附并收起成浅灰色细条，点击细条即可恢复。

设置界面采用与悬浮窗一致的深色配色，也可以从非按钮区域拖动。

设置界面包含：

- CPU 使用率、CPU 温度、下载和上传的独立开关（首次运行默认全部打开）；
- 是否显示实时网速曲线，以及 1 分钟、5 分钟或 10 分钟时间范围；
- 是否使用迷你长条模式，以及是否在靠近屏幕边缘时自动收起；
- 温度传感器选择，默认自动选择；
- 是否启动时请求管理员权限，默认关闭；
- 窗口置顶和开机自动启动。

## 自己编译

要求：Windows 10/11 x64、.NET 8 SDK。

在 PowerShell 中运行：

```powershell
.\Build.ps1
```

脚本会发布一个包含 .NET 运行时的单文件版本：

```text
publish\CpuNetWidget.exe
```

如果希望生成体积更小、依赖本机 .NET 8 Desktop Runtime 的版本：

```powershell
.\Build.ps1 -FrameworkDependent
```

## 温度读取说明

温度传感器优先通过 `LibreHardwareMonitorLib` 读取，无硬件数据时回退到 Windows ACPI 温区。由于硬件和主板固件存在差异：

- 少部分电脑需要在设置中启用“启动时请求管理员权限”才能读取 CPU Package；
- 某些主板不对 Windows 暴露 CPU 温度，此时界面会显示 `--°C`；
- CPU 使用率与网络速率无需管理员权限。

启用高权限后，程序下次启动会显示标准 Windows UAC 确认；关闭后不会请求管理员权限。当前温度来源会直接显示在温度数值下方。

https://github.com/LibreHardwareMonitor/LibreHardwareMonitor
